#  SnakeRush

SnakeRush is a simple Snake Game developed using Python and Pygame.

## 🎮 Features

- Blue square snake
- Apple food
- Food eating sound
- Score and High Score
- Keyboard controls
- Game Over screen
- Restart option
- Simple background

##  Controls

- ↑ — Move Up
- ↓ — Move Down
- ← — Move Left
- → — Move Right
- SPACE — Start Game
- R — Restart after Game Over

## Technologies Used

- Python
- Pygame

## How to Run

First, install Pygame:

```bash
pip install pygame
```

Then run the game:

```bash
python snake_game.py
```

## Project Files

- `snake_game.py` — Main game code
- `apple.png` — Apple image
- `food.mp3` — Food eating sound
